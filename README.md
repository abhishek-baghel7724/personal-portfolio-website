# Abhishek Baghel — Portfolio

Responsive single-page portfolio built with HTML, CSS and JavaScript.

## Personalize before publishing
- Replace `yourusername` in GitHub and LinkedIn links.
- Replace `your.email@example.com` with your email address.
- Add your resume PDF at `assets/Abhishek_Baghel_Resume.pdf`.
- Replace the project links with their individual repository URLs.

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Live Website

- **Portfolio:** https://abhishek-baghel7724.github.io/personal-portfolio-website/
- **GitHub Repository:** https://github.com/abhishek-baghel7724/personal-portfolio-website

> If the portfolio link is not opening yet, enable GitHub Pages in **Settings → Pages** and select the `main` branch with the `/(root)` folder. The site will appear after GitHub completes deployment.
